Access to Everyday Life: Seattle Sidewalk Accessibility

Cities shape how people move, navigate, and participate in everyday life. Using the Project Sidewalk Seattle Accessibility Dataset, this project explores where mobility breaks down, how accessibility varies across neighborhoods, and which barriers most impact independent movement.

Mobility Friction Zones

This map highlights areas where accessibility barriers cluster, creating zones where pedestrian movement may be slowed or unsafe.

Accessibility Score by Neighborhood

We compute an Accessibility Score that inverts barrier severity so that higher values indicate more accessible neighborhoods.

Key Insights

  • Accessibility challenges cluster along specific corridors.
  • Some neighborhoods face consistently higher mobility friction.
  • Temporary barriers can still produce significant accessibility impacts.
